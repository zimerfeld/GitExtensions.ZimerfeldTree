GitExtensions.ZimerfeldTree

Branches as a hierarchical tree, one-click GitFlow, and a Restore hub to safely go back in time — right inside GitExtensions.

Branches em árvore hierárquica, GitFlow num clique e uma central Restore para voltar no tempo com segurança — dentro do GitExtensions.

Features

Funcionalidades

What GitExtensions.ZimerfeldTree brings to your GitExtensions.

O que o GitExtensions.ZimerfeldTree traz para o seu GitExtensions.

🌳

Hierarchical branch tree

Árvore hierárquica de branches

LOCAL, REMOTES & TAGS combining real commit ancestry with / path grouping; current branch in bold, live counters and a real-time filter.

LOCAL, REMOTES e TAGS combinando ancestralidade real de commits com agrupamento por caminho /; branch atual em negrito, contadores ao vivo e filtro em tempo real.

⚡

One-click GitFlow

GitFlow num clique

Start/publish/track/update/finish for feature, release, hotfix, bugfix and support — with a flexible hierarchy that even allows a feature under a feature.

Start/publish/track/update/finish para feature, release, hotfix, bugfix e support — com hierarquia flexível que permite até feature filha de feature.

↕️

Pull / Push / Commit at hand

Pull / Push / Commit à mão

Arrow buttons with ahead/behind counters, a background remote check, and a one-click pull with rebase, then push that clears non-fast-forward rejections.

Botões com contadores adiante/atrás, verificação do remoto em segundo plano e um baixar com rebase e então enviar num clique que resolve rejeições non-fast-forward.

⏪

Restore — go back in time

Restore — voltar no tempo

A dedicated hub for every safe recovery: restore, cherry-pick, revert, reflog recovery, create branch/tag from any commit — each with built-in guidance.

Uma central dedicada para toda recuperação segura: restaurar, cherry-pick, reverter, recuperação via reflog, criar branch/tag de qualquer commit — cada uma com orientação embutida.

🌐

Localized (EN / PT)

Localizado (EN / PT)

Every window picks its language independently and remembers it.

Cada janela escolhe seu idioma de forma independente e o memoriza.

🛡️

Developer mode

Modo Developer

Protects main/master/develop from risky operations and persists tree state per working directory.

Protege main/master/develop de operações arriscadas e persiste o estado da árvore por diretório de trabalho.

Installation

Instalação

Two ways to get up and running.

Duas formas de começar.

Plugin Manager (recommended)Gerenciador de Plugins (recomendado)
In GitExtensions, open Plugins → Plugin Manager, search for ZimerfeldTree and install. Restart, then open Plugins → ZimerfeldTree. No GitExtensions, abra Plugins → Plugin Manager, procure por ZimerfeldTree e instale. Reinicie e abra Plugins → ZimerfeldTree.
ManualManual
Install the NuGet package or drop the plugin DLL into C:\Program Files\GitExtensions\Plugins\. Instale o pacote NuGet ou copie a DLL do plugin para C:\Program Files\GitExtensions\Plugins\.

Requires GitExtensions 6.x (.NET 9) on Windows. Requer o GitExtensions 6.x (.NET 9) no Windows.
